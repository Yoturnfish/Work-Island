Work Island 使用教程

本地创作时长仪表盘 · macOS 15 及以上

一、安装 Work Island

  1. 双击 Work Island 0.8.23.dmg。
  2. 将 Work Island 拖入 Applications（应用程序） 文件夹。
  3. 本版本使用临时签名。若 macOS 拦截首次启动，请前往“系统设置 → 隐私与安全性”，在安全提示处选择仍要打开。
  4. 从“应用程序”打开 Work Island。

二、移动悬浮窗

将鼠标放在悬浮窗的进度条、文字或时间数字上，按住并拖动，即可调整位置。

三、进入导航页

点击悬浮窗左侧的时钟按钮，进入导航页。在这里可以打开设置、历史和识别，也可以暂停或继续计时。

四、首次使用与识别设置

首次使用时，请在识别页添加工作应用或网页规则；未添加规则时，Work Island 不会累计工作时长。

添加应用程序

  1. 展开“应用程序”。
  2. 点击“添加”。
  3. 选择需要统计的 Mac 应用。

添加网页路径

首次使用网页识别时，请进入“浏览器访问权限”，完成 Chrome、Edge 或 Safari 的权限认证。

  1. 点击“网页路径”右侧的“添加”。
  2. 输入网址中需要包含的关键词，例如 github。
  3. 当前网页的完整路径包含该关键词时，Work Island 会将其识别为工作内容。

Work Island 只在本机读取当前网页地址用于规则匹配；未命中规则的网址不会写入计时历史。

Work Island User Guide

A local creative-work time dashboard · macOS 15 or later

1. Install Work Island

  1. Double-click Work Island 0.8.23.dmg.
  2. Drag Work Island into the Applications folder.
  3. This build uses an ad-hoc signature. If macOS blocks the first launch, open System Settings → Privacy & Security and choose Open Anyway beside the security notice.
  4. Open Work Island from Applications.

2. Move the floating window

Click and drag the progress bar, title, or time digits to move the floating window.

3. Open navigation

Click the clock button on the left of the floating window to open navigation. From here, you can open Settings, History, or Tracking, and pause or resume the timer.

4. First use and tracking rules

On first use, add work apps or website rules on the Tracking page. Work Island will not accumulate work time until rules have been added.

Add an application

  1. Expand Applications.
  2. Click Add.
  3. Select the Mac apps you want to track.

Add a website path

Before using website tracking, open Browser Access and authorize Chrome, Edge, or Safari.

  1. Click Add beside Website paths.
  2. Enter a keyword that should appear in the URL, such as github.
  3. When the current page's full URL contains that keyword, Work Island recognizes it as work.

Work Island reads the current URL locally only to match your rules. URLs that do not match a rule are not written to time history.
